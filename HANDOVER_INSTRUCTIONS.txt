## Key Physical Insights

From transcripts and analysis:

1. **Geometric units**: Waveforms depend on Mf (mass × frequency), not f alone
   - Train on Mf grid, rescale by mass analytically
   - Similarly, time domain uses t/M for mass-independence

2. **Parameter space**: Maximum 7D (η + 6 spin components)
   - Aligned-spin case reduces to 3D: (η, χ₁z, χ₂z)
   - Extrinsic parameters (distance, phase, inclination) handled analytically

3. **Modes are additive**: h(f) = Σ_lm h_lm(f) to machine precision
   - Individual modes are MUCH smoother than full waveform
   - Wiggles in full waveform come from mode interference, not intrinsic complexity
   - **Strategy**: Emulate each mode separately, then sum

4. **Amplitude/phase vs real/imaginary**:
   - Amplitude and phase vary smoothly with parameters
   - Real/imaginary parts oscillate rapidly - hard to emulate
   - **Strategy**: Emulate log-amplitude and unwrapped phase

## Architecture Decisions

- **Waveform model**: IMRPhenomXPHM (with aligned spins reduces to XHM)
- **Emulation strategy**: Per-mode, not full waveform
- **Representation**: Log-amplitude + unwrapped phase (not real/imag)
- **Framework**: JAX/Flax with Speculator activation
- **Compression**: PCA on amplitude and phase separately
- **Validation target**: Mismatch < 10⁻³

## Neural Network Details

From `snippets/flax_nn.py`:

- **SpeculatorActivation**: σ(x) = [γ + sigmoid(αx)·(1-γ)]·x
  - γ constrained to (0,1) via sigmoid on learnable logits
  - gamma_logits initialized to -2.0 (mostly gated - empirically best)

- **EmulatorMLP**: 4 hidden layers × 512 units
  - Input: normalized (η, χ₁z, χ₂z)
  - Output: PCA coefficients
  - ~820k parameters

- **Training**: AdamW with gradient clipping (1.0), warmup + cosine decay

## Next Steps (Priority Order)

### 1. Data Generation Script
Create `scripts/generate_training_data.py`:
- Sample (η, χ₁z, χ₂z) using Latin Hypercube
- Generate EACH MODE separately on Mf grid
- Store amplitude and phase (not complex strain)
- Target: 10⁵ training, 10⁴ validation samples

```python
# Parameter ranges:
# eta ∈ [0.05, 0.25]
# chi1z, chi2z ∈ [-0.99, 0.99]
# Mf grid: log-spaced, ~1000 points in [0.003, 0.25]

# Modes to generate:
# (2,2), (2,1), (3,3), (3,2), (4,4)
```

### 2. Per-Mode PCA
Fit PCA separately for each mode's amplitude and phase:
- Different modes have different dynamical ranges
- (2,2) dominates inspiral, higher modes dominate ringdown

### 3. Per-Mode Neural Networks
Train separate networks (or shared backbone with mode-specific heads):
- Start with (2,2) - dominant mode, easiest
- Add subdominant modes incrementally

### 4. Validation
- Compute mismatch: emulated vs LAL across parameter space
- Target: mismatch < 10⁻³ for each mode
